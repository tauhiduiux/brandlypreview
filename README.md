# Brandly Preview

Single-page Tailwind CSS template showcase with home previews, inner-page galleries and hero motion.

Run `npm run build`; serve the generated `public/` folder. Vercel uses the included configuration.

Editable HTML, CSS and JavaScript are in `src/`. Screenshot assets are losslessly encoded in JSON bundles under `assets/`; the build restores the original WebP/PNG files. No runtime asset decoding is required.
